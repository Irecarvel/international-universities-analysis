# Análisis de Universidades Internacionales (THE Ranking) 🌍📊

Proyecto práctico de nivel Junior/Data Entry enfocado en el análisis del impacto de la internacionalización en la educación superior global.

## 🛠️ Herramientas Utilizadas
* **Excel:** Limpieza de datos (Data Cleansing) y estandarización de formatos numéricos.
* **SQL (DBeaver / SQLite):** Extracción de métricas clave y segmentación de datos.
* **Looker Studio:** Construcción de un dashboard interactivo para la visualización de resultados.

## 📁 Fuente de Datos
Los datos utilizados son reales y públicos, extraídos del dataset oficial de **Times Higher Education (THE) World University Rankings**.

## 📊 Consultas SQL Desarrolladas
En este proyecto respondí a tres preguntas de negocio mediante scripts de SQL:
1. **Top 5 países en el Top 100** y su promedio de alumnos internacionales.
2. **Relación** entre el porcentaje de internacionales y la puntuación de enseñanza.
3. **Eficiencia de personal** en las 10 universidades más masificadas del Top 50.
